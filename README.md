# 块属性管理器

一款[思源笔记](https://b3log.org/siyuan/)插件，在侧栏面板中实时展示当前光标所在块的属性，并支持快速内联编辑。

## 功能特性

- **实时块追踪** -- 面板自动跟随光标，点击或导航到任意块时即时显示其属性
- **内部属性与自定义属性分离** -- 系统维护字段（id、type 等）以只读方式展示，用户可编辑字段（name、alias、memo、bookmark、title、tags）始终可见并可直接编辑
- **自定义属性管理** -- 在面板中直接添加、编辑或删除 `custom-` 前缀的自定义属性
- **内联编辑** -- 点击可编辑的值即可就地修改，失焦即保存
- **乐观更新** -- 编辑后 UI 立即响应，网络异常时自动回滚
- **可视化状态指示** -- 每行显示保存中 / 已保存 / 失败的状态标识
- **可折叠分组** -- 内部属性和自定义属性可独立折叠，状态跨会话持久化
- **多语言** -- 开箱支持简体中文和英文


## 使用方法

1. 点击右侧栏的插件图标打开属性面板
2. 在编辑器中点击任意块，面板即显示该块的属性
3. **编辑属性值**：点击值文本进入编辑状态，修改后点击其他位置或按 Enter 保存
4. **添加自定义属性**：在"自定义属性"区域底部的输入行中填写属性名（无需输入 `custom-` 前缀）和值，按 Enter 或点击确认按钮添加
5. **删除自定义属性**：鼠标悬停在对应行上，点击 **x** 按钮即可删除
