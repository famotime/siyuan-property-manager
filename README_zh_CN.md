# 属性管家 (Property Manager)

> 专为 [思源笔记 (SiYuan Note)](https://b3log.org/siyuan/) 打造的块属性全生命周期管理与数据化增强插件。
> 让沉淀在块和文档中的元数据（Attributes）变得 **可见、可控、类型化、可复用、可统计、可表格化**。

---

## 🌟 为什么需要「属性管家」？

在思源笔记中，**属性（Attributes）** 是连接自由文本笔记与结构化知识库的核心纽带。然而在日常使用中，沉淀元数据往往面临诸多痛点：

| 痛点场景 | 传统使用困扰 | 「属性管家」带来的转变 |
| :--- | :--- | :--- |
| **查看与编辑** | 必须通过多级右键菜单或深层面板，操作路径长，打断沉浸写作思路 | **光标毫秒级跟随**，侧边栏 Dock、文档顶部内联面板与移动端抽屉随时随地就地编辑 |
| **数据类型混乱** | 原生自定义属性全为纯文本，无法做单选、多选、日期、布尔等格式约束 | **7 大强类型字段与专用控件**（单选彩色胶囊、多选标签、日期、布尔、块关联等） |
| **重复配置低效** | 为相似笔记反复输入一长串属性名与初值，费时费力且容易出现拼写不一致 | **一键存为模板 & 秒级批量套用**，规范知识库元数据录入标准 |
| **元数据黑盒** | 无法全局掌控笔记本中标记了哪些属性、哪些值被频繁使用、哪些块打了标记 | **双层全景统计看板**，支持按属性名/值数/块数多维排序与展开下钻溯源 |
| **重构代价高昂** | 分类体系或标签调整时，想要修改属性值只能手动搜索并逐块修改 | **可视化多选批量编辑与清理**，一键全局替换数百个块的属性值 |
| **笔记与表格割裂** | 散落在各处的笔记块虽然拥有相同属性，但难以聚合为多维表格视图 | **按模板智能聚合块并一键生成思源原生数据库（Attribute View）** |

## 🎯 核心使用场景与用户价值

### 场景一：沉浸式笔记中的元数据即时捕获
- **问题**：阅读文献、记录任务或撰写卡片笔记时，经常需要给段落打上状态、评分、分类或备注，但频繁打开右键菜单严重破坏心流。
- **解决方案**：
  - **光标智能感知**：桌面端右侧 Dock 栏随光标焦点毫秒级切换，实时呈现当前块（或当前文档）的所有内部属性与自定义属性。
  - **文档顶部内联面板**：在文档标题与正文之间无缝嵌入紧凑属性栏，支持折叠与状态记忆，自适应文档排版宽度。
  - **移动端专属抽屉**：移动端顶部一键唤起属性抽屉，随时随地在手机或平板上便捷查看与调整块属性。
  - **就地编辑与防抖保存**：点击属性值直接修改，失焦或回车立即保存；深度集成思源 `ws-main` 事务流，多端并发与多窗口修改实时无感同步。

### 场景二：专业类型化体系与标准化录入（Schema）
- **问题**：自由文本输入容易产生错别字与格式不一致（例如 `status` 混用了“待办”、“TODO”、“todo”），导致后续检索和过滤失效。
- **解决方案**：
  - **7 种专业数据类型**：支持 **文本 (Text)、数字 (Number)、单选 (Select)、多选 (Multi-Select)、日期 (Date)、布尔 (Checkbox)、块关联 (Block Reference)**。
  - **开箱即用预设**：内置状态（待办/进行中/已完成/挂起）、优先级（P0/P1/P2/P3）、分类、进度百分比、截止日期、项目、评分等多套常见场景规则。
  - **定制化交互控件**：
    - 单选/多选：直观的彩色胶囊下拉与标签选择器，支持实时检索与动态新建选项。
    - 日期：快捷选择「今天/明天/昨天」或通过日历挑选日期。
    - 布尔：清晰的真/假状态切换。
    - 块关联：在属性面板中直接输入关键词，穿透搜索全知识库文档与块并一键建立关联。
  - **全局类型管理中心**：在设置中集中管理所有属性的字段类型、选项池颜色、重命名或一键恢复默认预设。

### 场景三：知识体系标准化与模板秒级复用
- **问题**：建立读书笔记、会议纪要或项目文档时，每次都要手动输入相同的 5-10 个属性名。
- **解决方案**：
  - **一键提取为模板**：将任意已配置好属性的块，一键保存为可复用的属性模板。
  - **模板即点即用**：在模板库中点击「应用到当前块」，瞬间向当前块注入完整的属性结构，大幅削减重复劳动。

### 场景四：全景元数据资产看板与下钻溯源
- **问题**：笔记日积月累，想知道全库到底标记了哪些属性、某个标签关联了哪些具体内容如同大海捞针。
- **解决方案**：
  - **文档与笔记本双层统计**：汇总当前文档与全笔记本的自定义属性分布，直观展示每个属性名称、取值去重数以及关联块总数。
  - **多维灵活排序**：支持按属性名称、属性值数量、引用块数量升降序排列。
  - **多级下钻与穿透定位**：展开属性值即可查看拥有该属性的所有具体块卡片（含所在文档面包屑路径与内容摘要），支持一键复制块 ID，点击平滑跨文档跳转并高亮聚焦目标块。

### 场景五：大规模属性清洗与秒级批量重构
- **问题**：工作流升级或标签体系重构时，需要将旧属性值批量变更为新名称，或者清理过时属性。
- **解决方案**：
  - **批量重命名**：在统计看板中开启「批量编辑」模式，勾选一个或多个属性值，输入新值后一键全局批量替换，瞬间同步更新关联的数十上百个块。
  - **批量清理**：勾选目标属性值一键批量移除，彻底告别机械重复的手工修改。

### 场景六：零散笔记到原生数据库（Attribute View）的一键跃迁
- **问题**：散落在各处的笔记块虽然标注了统一属性，但无法像 Notion 数据库或思源多维表格一样集中筛选、排序与展示。
- **解决方案**：
  - **按模板属性智能聚合**：基于属性模板，在当前文档或全笔记本中自动筛选包含该模板所有属性的全部块。
  - **一键生成思源原生数据库**：选定筛选出的笔记块后，一键自动创建并插入思源原生数据库（Attribute View），将零散笔记块作为主键行自动绑定，并以模板名作为数据库名称，实现从自由笔记到结构化表格的无缝升级。

### 场景七：笔记本数据库资产全景盘点
- **问题**：在各个文档中创建了多个数据库表格，后期难以跟踪和统计各表格的数据量与绑定状态。
- **解决方案**：
  - **数据库全景统计**：集中列出当前笔记本内所有属性视图（Attribute View）的名称、数据行数、绑定块数、创建与更新时间，并支持一键跳转到对应绑定块。

## 🛠️ 开箱即用类型预设（示例）

插件内置了多套符合知识管理最佳实践的预设属性，安装后即可直接在专用控件中点选使用：

- **`custom-status`（状态）**：单选类型（待办、进行中、已完成、挂起、已取消），带有彩色徽章标识。
- **`custom-priority`（优先级）**：单选类型（P0 - 紧急、P1 - 高、P2 - 中、P3 - 低）。
- **`custom-category`（分类）**：单选类型（事实、疑问、经验、方法、灵感、信息）。
- **`custom-progress`（进度）**：数字类型，记录任务完成百分比。
- **`custom-deadline` / `custom-start-date`（日期）**：日期类型，支持今天/明天/昨天快捷赋值。
- **`custom-relation`（关联）**：块关联类型，输入关键词即可快速关联知识库中的其他文档或块。
- **`custom-starred` / `custom-archived`（标记）**：布尔类型，快捷打上重点或归档标记。

> 💡 **提示**：您可以在「设置 > 插件设置 > 属性管家 > 全局属性类型管理」中自由修改、删除这些预设，或添加属于您自己的类型规则。

## 🚀 快速上手

### 1. 安装方式

#### 方式一：思源集市安装（推荐）
1. 打开思源笔记 **设置** > **集市** > **插件**。
2. 搜索 `属性管家` 或 `Property Manager`。
3. 点击 **安装** 并启用插件。

#### 方式二：手动安装
1. 从 [GitHub Releases](https://github.com/famotime/siyuan-property-manager/releases) 下载最新的 `package.zip`。
2. 解压至思源工作空间的 `data/plugins/siyuan-property-manager/` 目录。
3. 重启思源笔记，在 **设置** > **集市** > **已安装** 中启用插件。

```

│                      属性管家工作流                    │

│ 光标实时跟随 │ 7 大专业控件 │ 全景统计看板 │ 模板聚合  │
```

#### ① 快速查看与就地编辑
- **侧边栏**：点击右侧边栏的 **属性管家** 图标展开面板，点击编辑器中任意块，面板实时同步属性；直接点击属性值即可就地修改。
- **文档内联栏**：在文档正文上方即可看到当前文档的属性栏，点击右侧按钮可随时折叠/展开。
- **移动端**：点击顶部栏的属性管家图标即可唤起底部操作抽屉。

#### ② 添加类型化属性与设置类型
- 在「自定义属性」下方输入属性名（如 `status` 或 `deadline`），系统将自动匹配对应的类型控件（如单选胶囊或日期选择器）。
- 点击属性名左侧的类型图标，可随时切换该属性的字段类型。

#### ③ 制作与套用属性模板
- 配置好某个块的属性后，点击自定义属性栏右侧的 **存为模板**。
- 随后在其他块中，点击模板列表中的 **应用到当前块**，即可秒级套用完整的属性结构。

#### ④ 属性统计、下钻与批量重构
- 切换到面板顶部的 **「属性统计」** 标签页。
- **查阅与下钻**：查看全笔记本各属性的使用频次，点击属性值展开查看关联的具体块列表，点击任意卡片即可跨文档精准跳转。
- **批量修改**：点击「批量编辑」开关，勾选要修改的一个或多个值，输入新值后一键全局替换。

#### ⑤ 从笔记块一键生成原生数据库
- 在「按属性模板聚合」中选择模板，点击 **归类筛选** 预览符合条件的笔记块。
- 点击 **创建数据库**，插件将自动在当前位置插入思源原生数据库（Attribute View），将筛选的块作为行数据绑定，并自动填入对应属性值。

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 属性管家保存的数据安全吗？卸载插件后数据会丢失吗？</b></summary>
<b>完全安全。</b> 本插件操作的全部是思源笔记原生的块属性（Block Attributes）和原生属性视图（Attribute View）。所有属性直接写入笔记底层数据库与 Markdown 文件中。即使停用或卸载插件，所有块属性依然完好无损地保留在您的笔记中。
</details>

<details>
<summary><b>Q2: 什么是自定义属性？属性名前面需要手动输入 <code>custom-</code> 吗？</b></summary>
<b>不需要。</b> 思源笔记底层规范使用 <code>custom-</code> 前缀区分自定义属性。在使用本插件时，您只需输入直观的属性名称（如 <code>status</code>、<code>priority</code>、<code>author</code>），插件会自动处理底层前缀，为您呈现简洁干净的界面。
</details>

<details>
<summary><b>Q3: 文档顶部的内联属性栏如果不想要，可以关闭或收起吗？</b></summary>
可以。文档顶部的内联属性栏右侧提供了折叠按钮，折叠后状态会自动保存；若不需要内联栏，也可以在插件设置中关闭该功能。
</details>

<details>
<summary><b>Q4: 生成的数据库是第三方格式还是思源原生格式？</b></summary>
生成的数据库是 <b>思源笔记 100% 原生属性视图（Attribute View）</b>。生成后您可以自由使用思源原生的各种视图类型（表格、看板、画廊等）、过滤排序和统计汇总功能。
</details>
