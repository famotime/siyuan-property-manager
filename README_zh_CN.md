# 属性管家 (Property Manager)

一款[思源笔记](https://b3log.org/siyuan/)插件，在侧栏面板中实时展示、编辑当前块的属性，并提供文档级和笔记本级的属性统计分析。

## 使用场景

### 场景一：快速查看和编辑块属性
当你在编辑笔记时，想要查看或修改某个块的自定义属性（如标签、分类、状态等），无需通过繁琐的右键菜单。只需点击任意块，右侧栏的属性面板即刻展示该块的所有属性。

### 场景二：批量管理属性值
如果你在多个块中使用了相同的属性值（如 `custom-category=读书笔记`），想要批量修改为新值，可以通过"属性统计"标签页一键完成，无需逐个手动修改。

### 场景三：查找使用特定属性的块
想要找出所有标记了某个自定义属性的块？属性统计功能会按属性名分组显示所有值及其出现次数，点击即可快速跳转到对应块。

## 功能特性

### 属性编辑

- **实时块追踪** -- 面板自动跟随光标，点击或导航到任意块时即时显示其属性
- **内部属性与自定义属性分离** -- 系统维护字段（id、type 等）以只读方式展示，用户可编辑字段（name、alias、memo、bookmark、title、tags）始终可见并可直接编辑
- **自定义属性管理** -- 在面板中直接添加、编辑或删除 `custom-` 前缀的自定义属性
- **内联编辑** -- 点击可编辑的值即可就地修改，失焦即保存
- **乐观更新** -- 编辑后 UI 立即响应，网络异常时自动回滚
- **可视化状态指示** -- 每行显示保存中 / 已保存 / 失败的状态标识
- **可折叠分组** -- 内部属性和自定义属性可独立折叠，状态跨会话持久化

### 属性统计

- **文档自定义属性块** -- 当前文档中所有包含自定义属性的块列表，一键跳转到对应位置
- **笔记本自定义属性统计** -- 按属性名分组，显示当前笔记本中所有自定义属性值及其使用次数
- **悬浮编辑** -- 鼠标悬停在统计值上即可快速编辑或删除该属性值
- **批量操作** -- 勾选多个属性值后，可批量编辑或批量删除，提升管理效率
- **块跳转** -- 点击文档自定义属性块列表中的任意项，可直接跳转到该块在编辑器中的位置

### 其他特性

- **多语言** -- 开箱支持简体中文和英文
- **设置项** -- 可选开启属性统计日志，方便诊断问题

## 安装方式

1. 在思源笔记中打开 **设置** > **集市** > **插件**
2. 搜索"属性管家"或"Property Manager"
3. 点击 **安装** 并启用插件

或者手动安装：
1. 从 [GitHub Releases](https://github.com/Wetoria/siyuan-property-manager/releases) 下载 `package.zip`
2. 解压到思源工作空间的 `data/plugins/siyuan-property-manager/` 目录
3. 重启思源笔记，在 **设置** > **集市** > **已安装** 中启用插件

## 使用方法

### 查看和编辑属性

1. 点击右侧栏的插件图标打开属性面板
2. 在编辑器中点击任意块，面板即显示该块的属性
3. **编辑属性值**：点击值文本进入编辑状态，修改后点击其他位置或按 Enter 保存
4. **添加自定义属性**：在"自定义属性"区域底部的输入行中填写属性名（无需输入 `custom-` 前缀）和值，按 Enter 或点击确认按钮添加
5. **删除自定义属性**：鼠标悬停在对应行上，点击 **x** 按钮即可删除

### 使用属性统计

1. 点击面板顶部的 **属性统计** 标签页
2. **文档自定义属性块**：查看当前文档中所有包含自定义属性的块，点击可跳转
3. **笔记本自定义属性统计**：
   - 查看当前笔记本中所有自定义属性值及其使用次数
   - 悬停在某个值上，点击编辑图标可修改该值（将批量更新所有使用该值的块）
   - 点击删除图标可删除该值（将从所有使用该值的块中移除）
   - 勾选多个值后，点击批量编辑或批量删除按钮进行批量操作
